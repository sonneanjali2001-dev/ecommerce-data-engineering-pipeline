# 🛒 E-Commerce Data Engineering Pipeline

## 📌 Project Overview
An end-to-end data engineering project designed to ingest, process, transform, and analyse e-commerce data using modern cloud technologies.

## 🛠️ Technologies Used
- Azure Data Factory (ADF)
- Azure Data Lake Storage Gen2
- Microsoft Fabric Lakehouse
- PySpark
- Delta Lake
- SQL
- Power BI

## 🏗️ Architecture
The project follows the Medallion Architecture:

- **Landing:** Raw data ingestion.
- **Bronze:** Stores raw data in Delta format.
- **Silver:** Data cleaning and transformation.
- **Gold:** Business-ready datasets for analytics.

## 📊 Key Analysis
- Regional sales analysis
- Order and delivery performance
- Customer analysis
- Revenue and discount analysis
- Delivery SLA monitoring

## 🎯 Objective
To build a scalable data pipeline and transform raw e-commerce data into meaningful business insights.
